# Mistrz Gry 🎲

Prosta aplikacja webowa do prowadzenia kampanii RPG głosem.

## Funkcje
- Mistrz Gry i wielu graczy.
- Każda osoba może nagrać wiadomość głosową.
- Historia sesji pokazuje kolejne wiadomości audio.

## Uruchomienie
Wystarczy otworzyć `index.html` w nowoczesnej przeglądarce (Chrome/Edge/Firefox).

Dla lokalnego serwera (opcjonalnie):

```bash
python3 -m http.server 8080
```

Następnie otwórz `http://localhost:8080`.

## Uwaga
Aplikacja działa w przeglądarce i wymaga zgody na dostęp do mikrofonu.
